# Dota 2 Meta Assistant

Настольное Windows-приложение для анализа меты Dota 2: реальная статистика OpenDota, сборки предметов по этапам игры, прокачка способностей, таланты и контры. Все данные загружаются из открытых API и кэшируются локально.

## Готовый запуск (ZIP)

1. На странице репозитория нажмите зелёную кнопку **«<> Code»** → **«Download ZIP»**.
2. Распакуйте архив в любую папку.
3. Запустите `join.bat` — он соединит две части exe в один файл (GitHub не позволяет файлы больше 100 МБ, поэтому exe разрезан на `*.part1` и `*.part2`).
4. Запустите `Dota2-Meta-Assistant-1.0.0-portable.exe` из корня распакованной папки. Установка не требуется.
4. При первом запуске приложение загрузит данные OpenDota (нужен интернет). Потом используется локальный кэш, обновление идёт в фоне.
5. Кнопка обновления — стрелка в верхней панели; дата обновления — на главной и в «Настройках».

В состав ZIP уже входит `bin/code.exe` — вложенная программа, которая запускается по паролю из раздела «Настройки». Путь к ней вычисляется относительно самого приложения, поэтому работает у любого пользователя и при любом имени папки.

> Если Windows показывает «Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае». Файл не подписан цифровой подписью. Дополнительно можно ПКМ по exe → Свойства → «Разблокировать».

## Возможности

- **Мета-дашборд**: текущий патч, дата обновления, объём выборки, сильнейшие герои, тренды роста/падения, топ по позициям, фильтры по роли, рангу, винрейту и пикрейту.
- **Каталог 127 героев**: поиск, фильтрация по позициям и сортировка, винрейт/пикрейт/банрейт, тир эффективности.
- **Страница героя**: базовые параметры, сильные и слабые стороны, сборка по 5 этапам (старт, ранняя, средняя, поздняя, финальные предметы), таблица прокачки способностей по уровням, приоритет навыков, древо талантов 10/15/20/25, лучшие и худшие матчапы.
- **Анализ изменений меты**: сравнение патчей по винрейту, пикрейту и банрейту с указанием объёма выборки и категориями изменений.
- **Переключение патчей**: кнопка с номером патча в верхней панели или селектор в «Настройках». Патч 7.41 содержит ~9.3K матчей — статистика и сборки стабильнее, чем свежий 7.42 (44 матча). Выбор запоминается между запусками.
- **Поиск с учётом русской раскладки**: латинское имя находится, даже если включена кириллица (`фч` → `axe`).
- **Позиции из реальных матчей**: роль (Carry / Mid / Offlane / Soft Support / Hard Support) выводится из `lane_role` OpenDota.
- **Автообновление и кэш**: проверка при запуске, ручное обновление, локальный кэш данных и изображений, работа в offline с предупреждением об актуальности.
- **Собственная иконка** `build/icon.ico`.

## Данные и честность

- Используется только публичный API OpenDota без ключа, без обхода авторизации и ограничений.
- Патч 7.42 вышел 18 ноября 2026 года. В открытой базе OpenDota по нему пока около 44 про-матчей, поэтому:
  - основная статистика берётся из `/heroStats` (большая выборка публичных матчей) и помечается как «публичный винрейт»;
  - сравнение патчей показывается с явным предупреждением о малой выборке;
  - сборки/таланты/контры при нехватке данных текущего патча считаются по последним 30 дням и помечаются как «последние 30 дней (данных патча мало)».
- Никакие показатели не выдумываются. Если данных нет, отображается прочерк или сообщение.

## Разработка

```bash
npm install
npm run dev        # Vite + Electron (dev-режим)
npm run typecheck
npm run build      # сборка portable .exe в release/
```

## Обновление

- **Пользователю**: закройте приложение, скачайте новую версию `Dota2-Meta-Assistant-*.exe` и запустите её. Локальный кэш сохранится в профиле пользователя. Для принудительной перезагрузки данных используйте кнопку обновления или «Очистить кэш» в настройках.
- **Разработчику**: измените версию в `package.json`, выполните `npm run build`, замените exe в `release/`.

## Структура

```
src/
  main/        Electron main-process: API-клиент, Explorer-SQL, кэш, кэш изображений,
               агрегация сборок и матчапов, IPC, окно
  shared/      типы данных
  renderer/    React-интерфейс: компоненты и экраны
release/       готовая portable-сборка
```

## Ограничения

- Сборки и матчапы — статистический ориентир на основе реальных матчей, а не персональный тренер: они не учитывают состав команды и конкретную игровую ситуацию.
- OpenDota не предоставляет публичный API с кураторскими гайдами; все рекомендации вычисляются из матчей.
- Изображения Dota 2 предоставляются CDN Valve и используются в информационных целях.
