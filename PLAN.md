# Архитектура и план разработки

## Выбор стека

Рассматривались Tauri и Electron. **Выбран Electron + React + TypeScript**: в окружении отсутствует Rust/Cargo, а его установка потребовала бы изменений системы вне папки проекта. Electron позволяет собрать готовый Windows `.exe` только средствами Node.js. Сборка — `electron-builder`, формат portable x64.

## Модули

### Главный процесс (`src/main/`)
- `apiClient.ts` — HTTP-клиент OpenDota с таймаутами, ретраями и ограничением частоты запросов.
- `explorer.ts` — SQL-запросы к OpenDota Explorer (`dataService.ts` содержит готовые SQL-шаблоны).
- `dataService.ts` — загрузка справочников, вычисление статистики по патчам, сборка `AppSnapshot`, stale-fallback.
- `builds.ts` — агрегация покупок по времени из `purchase_log`, порядка способностей и талантов из `ability_upgrades_arr`.
- `matchups.ts` — расчёт винрейта против каждого героя из `picks_bans`.
- `cache.ts` — дисковый кэш JSON с временной меткой и очисткой.
- `images.ts` — загрузка и дисковый кэш изображений; кастомный протокол `d2img://image/<encoded-url>`.
- `ipc.ts` / `preload.ts` — безопасный мост `contextBridge` между процессами.
- `main.ts` — окно без системной рамки, кастомные кнопки, современный тёмный фон.

### Рендерер (`src/renderer/`)
- `App.tsx` — состояние приложения, навигация, загрузка/обновление.
- `components/` — TopBar, BottomNav, HeroCard, ItemIcon.
- `screens/` — HomeScreen, HeroesScreen, HeroDetailScreen, MetaAnalysisScreen, SettingsScreen.
- `styles.css` — единая тёмная дизайн-система: графит, красный и золотой акценты, карточки, мягкие анимации.

## Поток данных

1. Старт: рендерер вызывает `data:bootstrap`.
2. Главный процесс читает кэш; если он свежий (< 20 мин) — отдаёт сразу.
3. Иначе параллельно загружаются 7 справочников и 6 SQL-агрегатов, данные сливаются в `AppSnapshot` и сохраняются.
4. При ошибке сети возвращается последний кэш с флагом `stale: true`.
5. Сборки и матчапы загружаются лениво при открытии страницы героя и кэшируются отдельно (4 ч / 12 ч).
6. Изображения идут через протокол `d2img`, кэшируются на диске и не загружаются повторно.

## Контроль качества

- `npm run typecheck` — строгая проверка TypeScript обоих процессов.
- Тест главного модуля на реальных API (временный `test-main.js`) — проверка патча, выборок, 127 героев, сборки и контров.
- Визуальная проверка собранного `.exe`: главная, карточки, загрузка изображений, страница героя, сборки, таланты.
- Честная маркировка малой выборки патча 7.42 и отсутствие выдуманных значений.
